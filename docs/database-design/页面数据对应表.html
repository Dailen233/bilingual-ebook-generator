逐表「谁在何时创建/更新」一句话

表谁在什么页面、何时
user用户/管理员在注册页或受控 CLI 创建；资料更新时更新 updated_at；管理员停用写 status/disabled_*
user_session后端在登录接口创建；退出接口撤销（revoked_at）
upload_file用户创建任务页上传成功后由后端创建
task用户创建任务页提交后创建（pending）；后台任务推进更新 status/stage/计数；重试新建
chapter/paragraph/translation_unit后台任务在提取/切分阶段批量写入；翻译阶段更新单元状态
book后台完成流程在完成事务内创建（book → book_file → task.status=done）
book_file后台完成流程在 book 之后创建（format=epub）
report用户在阅读页/书库举报（对象用户/书籍二选一）时创建（pending）；管理员审核受控推进 status（状态实体，非 append-only）
disposition管理员在审核页处置时创建（append-only）；同事务落到 user.status 或 book.status
audit_log管理员在审核上下文查看私有内容时写入（report_id 结构化关联；append-only）
bookmark用户在阅读器添加书签时创建（校验有权访问 + 段落属该书）
reading_progress用户翻页/离开阅读器时 upsert（每人每书一行；一致性校验同 bookmark）

持久化 vs 计算 vs 展示（汇总）

  • 持久化：user/user_session/upload_file/task/chapter/paragraph/translation_unit/book/book_file 全部字段；计划扩展的 report/disposition/audit_log/bookmark/reading_progress 全部字段，以及 user.status/disabled_*、book.status 计划扩展列。
  • 持久化展示快照（落库，非"纯展示"）：task.svc_name/model_name/style_name、book.svc_name/model_name/style_name 随任务/书落库，供任务详情/书库直接展示，不归入「不落库的纯展示数据」。
  • 计算/冗余聚合：task.total_units/done_units/failed_units（派生自 translation_unit.status）、book.failed_units（快照自 task）、进度百分比（done/total）、资源用量（聚合查询，不建表）。
  • 仅供展示（真正不落库）：原型 localStorage 模拟的顶栏昵称/头像、失败单元示例；前端即时计算的进度百分比。
