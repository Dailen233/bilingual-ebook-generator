# 字段字典（目标模型 · MySQL 8.4）

> 与 `schema.sql` 逐列一致；类型中的 `datetime6` = `DATETIME(6)` 无时区 UTC、`char64` = `CHAR(64)`、`varcharN` = `VARCHAR(N)`。实现状态列：✅ 已实现（对应 alembic 0001/0002）、✍ 本次拟定、❓ 设计建议。

## 状态合法值与转换

- `user.role`：`user` / `admin`（应用层校验，服务端判定权限）。
- `user_session.session_type`：`user` / `admin`；`revoked_at` 非空即失效。
- `task.status`：`pending → running → done|failed`；`done`/`failed` 为不可变终态；重试 = 新建 task（旧 failed 不变）。
- `task.stage`：`extract → align → translate → layout → export`（running 内推进）。
- `translation_unit.status`：`pending → translated|failed`（条件更新，不回退）。
- `book_file.format`：`epub`（首版）/ `pdf`（后续里程碑）。
