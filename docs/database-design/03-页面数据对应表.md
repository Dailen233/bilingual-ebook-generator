# 页面 → 数据实体与字段 → 写入角色/触发时机 → 实现状态

> 目的：逐表说明「谁在什么页面、何时创建或更新这条数据」，并区分**持久化字段**、**计算结果**（冗余聚合/派生）与**仅供展示**。
> 图例：✅ 已实现（yiban-web / yiban-admin / yiban-api 源码）；✍ 本次拟定设计（待实现）；▶ 仅供展示/前端模拟（不落库）。

## 逐表「谁在何时创建/更新」一句话

| 表 | 谁在什么页面、何时 |
|---|---|
| user | 用户/管理员在注册页或受控 CLI 创建；资料更新时更新 updated_at |
| user_session | 后端在登录接口创建；退出接口撤销（revoked_at） |
| upload_file | 用户创建任务页上传成功后由后端创建 |
| task | 用户创建任务页提交后创建（pending）；后台任务推进更新 status/stage/计数；重试新建 |
| chapter/paragraph/translation_unit | 后台任务在提取/切分阶段批量写入；翻译阶段更新单元状态 |
| book | 后台完成流程在 task 转 done 时幂等创建 |
| book_file | 后台完成流程在 EPUB 生成并落库后创建（book 之后） |

## 持久化 vs 计算 vs 展示（汇总）

- **持久化**：`user`/`user_session`/`upload_file`/`task`/`chapter`/`paragraph`/`translation_unit`/`book`/`book_file` 全部字段。
- **计算/冗余聚合**：`task.total_units/done_units/failed_units`（派生自 translation_unit.status）、`book.failed_units`（快照自 task）、进度百分比（`done/total`）。
- **仅供展示**：`svc_name/model_name/style_name`（冗余自配置，供书库/任务详情展示）；原型中顶栏昵称/头像、失败单元示例为 localStorage 模拟。
