字段字典（目标模型 · MySQL 8.4）

与 schema.sql 逐列一致；类型中的 datetime6 = DATETIME(6) 无时区 UTC、char64 = CHAR(64)、varcharN = VARCHAR(N)。实现状态列：✅ 已实现（对应 alembic 0001/0002）、✍ 本次拟定、⬜ 计划扩展（M2/M4 目标设计，非已实现）。
约定：所有主键 VARCHAR(36) UUID；枚举落 VARCHAR(16) + 应用层校验；时间列无 DB 默认值（应用层写 naive UTC）；外键默认 RESTRICT（不级联删除，用户用停用而非物理删除）。

状态合法值与转换

  • user.role：user / admin（应用层校验，服务端判定权限）。
  • user.status：active / disabled（M2；停用后登录与会话失效，不物理删除）。
  • user_session.session_type：user / admin；revoked_at 非空即失效。
  • task.status：pending → running → done|failed；done/failed 为不可变终态；重试 = 新建 task（旧 failed 不变）。
  • task.stage：extract → align → translate → layout → export（running 内推进）。
  • translation_unit.status：pending → translated|failed（条件更新，不回退；failed 为单元级失败）。
  • book.status：active / blocked / removed（M2；屏蔽/逻辑移除为审核处置落点，不物理删除）。
  • book_file.format：epub（首版）/ pdf（后续里程碑）。
  • report.status：pending → under_review → resolved|dismissed（pending/under_review 即审核队列；可受控更新，非 append-only）。
  • disposition.action：approve / reject / block / delete（落点见 disposition 承载方式说明）。

删除规则与索引

  • 外键删除规则：全库外键默认 RESTRICT（不 ON DELETE CASCADE）。用户不物理删除（用 user.status=disabled 停用）；任务/书/章节在其有结构或成果子行时不得删除；留痕/举报/处置默认保留（append-only，可追溯）。
  • 必要索引：所有外键列均建索引（列表/校验/联查）；状态列（task.status、report.status）建索引支撑队列筛选；复合唯一键（chapter(task_id,seq_no)、paragraph(chapter_id,seq_no)、translation_unit(paragraph_id,seq_no)、book_file(book_id,format)、reading_progress(user_id,book_id)）兼作保序与幂等。
  • 数值约束：size_bytes ≥ 0（upload_file 非空、book_file 可空时）；seq_no ≥ 1；retry_count ≥ 0；book.failed_units ≥ 0；task 计数器 0 ≤ failed_units ≤ done_units ≤ total_units（total_units/done_units/failed_units 均 ≥0，已落 CHECK，见 schema.sql）。
