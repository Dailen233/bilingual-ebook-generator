## 环境与边界

- **实例**：本机已有 MySQL **8.4.13**（`MySQL Community Server - GPL`）；连接端点 `127.0.0.1:3307`，服务器 `@@port` 报 `3306`（容器端口映射，属正常）。
- **独立库**：全新创建 `yiban_design_review`（utf8mb4 / utf8mb4_0900_ai_ci）。
- **绝不触碰**：`yiban_api_dev`（同实例 3307 上的业务库）与 `yiban_api_test`（另一实例 3308）均未连接、未执行、未修改；已验收迁移 0001/0002 未改动。
- **凭据**：仅经本机私有配置（`.env.dev-db`）注入到验证工具，**未打印、未提交、未写入任何 URL/报告**。
- **DDL 语义**：`CREATE TABLE` 在 MySQL 中隐式提交，**不依赖事务回滚**；合成测试数据在单事务内 `ROLLBACK`，验证后库内无残留数据。

## 复现命令（凭据经私有配置注入，不打印）

```bash
cd bilingual-ebook-generator
python3 scripts/md2html.py                 # 生成直读 HTML（可选）
python3 scripts/validate_design_mysql.py --env-file /path/to/私有.env.dev-db
```

> 工具读取 `MYSQL_ROOT_PASSWORD`/`MYSQL_PORT` 等，映射到 `YIBAN_MYSQL_*`；无凭据不打印。目标库非空时工具自动停止（不 DROP/TRUNCATE/覆盖）。若普通账号无建库权限，需先以具备 `CREATE` 权限的账号执行 `CREATE DATABASE yiban_design_review CHARACTER SET utf8mb4 COLLATE utf8mb4_0900_ai_ci;`（见《发布说明.md》）。
