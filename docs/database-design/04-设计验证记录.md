# 数据库设计验证记录（真实 MySQL 8.4 验收）

更新日期：2026-10-27。本记录为「目标模型 schema.sql 在独立设计验证库真实执行并通过」的验收证据，并如实区分「实际执行通过」与「仅准备工具」。

## 环境与边界

- **实例**：本机已有 MySQL **8.4.13**（`MySQL Community Server - GPL`）；连接端点固定 `127.0.0.1:3307`（服务器 `@@port` 报 `3306`，容器端口映射，属正常）。
- **独立库**：`yiban_design_review`（utf8mb4 / utf8mb4_0900_ai_ci）。
- **绝不触碰**：`yiban_api_dev`（同实例 3307 业务库）与 `yiban_api_test`（另一实例 3308）均未连接、未执行、未修改；已验收迁移 0001/0002 未改动。
- **硬保护**：工具固定端点 `127.0.0.1:3307`、库名 `yiban_design_review`、执行文件为本仓 `docs/database-design/schema.sql`，均不可经环境变量/参数改写；连接后先确认 8.4.x，不符合在任何 DDL 前停止。
- **凭据**：仅经本机私有配置（`.env.dev-db`）注入，**未打印、未提交、未写入任何 URL/报告**。
- **DDL 语义**：`CREATE TABLE` 在 MySQL 中隐式提交，**不依赖事务回滚**；合成测试数据在单事务内 `ROLLBACK`，验证后库内无残留数据。

## 一、只读深度核对（本轮实际执行，`--readonly`）

对已存在的 `yiban_design_review` 做纯只读深度核对（不建表、不删数据、不 DROP/TRUNCATE），把 `information_schema` 与 `schema.sql` **逐项**比对，而非只比总数：

| 核对项 | 实测 | 结论 |
|---|---|---|
| 表 + 表注释 | 14（逐表比名称 + 表注释） | ✅ |
| 列 | 114（逐列比名称、类型/长度、NULL、默认值、注释） | ✅ |
| 外键 | 24（逐名比源列、目标表、目标列） | ✅ |
| 主键/唯一键/索引 | 45 = schema.sql 声明 41（含主键 14）+ MySQL 自动外键索引 4；逐名比列顺序 + 唯一性 | ✅ |
| CHECK | 9（逐名比**所属表** + 定义**结构保持**：保留 AND/OR 与嵌套分组，非比较式集合 + 是否启用 ENFORCED=YES） | ✅ |

- 索引澄清：旧版只抽查「20 个关键索引/唯一键」的名称；现改为**全部声明索引（41）逐名/逐列/逐唯一性全量比对**。`bookmark.book_id`、`bookmark.paragraph_id`、`reading_progress.book_id`、`reading_progress.paragraph_id` 未在 schema.sql 显式声明单列索引，由 MySQL 为外键自动创建（名同外键约束，如 `fk_bookmark_book`），已作为预期建模并核对一致。
- CHECK 澄清：旧版把定义按 AND/OR 拆分、去括号并排序成「比较式集合」，会漏检 `a>=0 AND b>=0` 与 `a>=0 OR b>=0` 的差异、以及 `(a AND b) OR c` 与 `a AND (b OR c)` 的分组差异。现改为**结构保持的表达式树比较**（保留 AND/OR 与嵌套分组），并核对 CHECK **所属表**与 ENFORCED；无法解析时**显式失败**，不回退为忽略式比较。
- **结论**：`yiban_design_review` 与 `schema.sql` 逐表/逐列/逐注释/逐外键/逐索引/逐 CHECK 全部一致。

## 复现命令（凭据经私有配置注入，不打印）

```bash
cd bilingual-ebook-generator
python3 scripts/validate_design_mysql.py --selftest                       # 离线替身测试（无库）
python3 scripts/validate_design_mysql.py --env-file /path/to/私有.env.dev-db --readonly   # 只读深度核对
python3 scripts/validate_design_mysql.py --env-file /path/to/私有.env.dev-db              # 首次导入（要求库为空）
```

> 工具只读本机私有 `.env.dev-db` 的 `MYSQL_ROOT_PASSWORD`，映射端点固定为 `127.0.0.1:3307`、库名固定 `yiban_design_review`。写模式目标库非空即停止（不 DROP/TRUNCATE/覆盖）；已有库复核请用 `--readonly`。
