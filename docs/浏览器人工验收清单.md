## 普通用户路径

| # | 页面 | 检查点（桌面 / 390px 各一遍） | 通过 |
|---|---|---|---|
| U1 | 首页 index | 打开正常；顶栏含「登录/注册」入口；CTA「开始使用」跳登录；移动抽屉菜单项齐全 | ☐ |
| U2 | 注册 register | 空提交/两次密码不一致有校验提示；成功跳工作台 | ☐ |
| U3 | 登录 login | 邮箱/密码校验；示例账号直登跳工作台；「管理员入口」跳 admin-login | ☐ |
| U4 | 工作台 dashboard | 登录态顶栏（昵称/头像）；继续阅读卡；进行中任务卡；**失败任务区块**（有失败任务时可见）；空态文案；「创建任务/书库」入口 | ☐ |
| U5 | 创建任务 new-task | 空态提示；选示例文件；`.docx`/扫描版内联拦截且停留本步；语言/服务/风格选择；提交跳任务详情 | ☐ |
| U6 | 任务详情 task-detail | 处理中（进度环/阶段）；「模拟失败」→ 失败态（原因+重试）；完成态（对照示意+下载按钮+打开阅读）；空任务态；重试入口 | ☐ |
| U7 | 书库 library | 列表/搜索/语言筛选；空态与「无匹配」态；同名不同配置并列；阅读入口 | ☐ |
| U8 | 阅读器 reader | 对照渲染；视图/字号偏好；失败单元总数展示；无效 bookId「找不到这本书」；返回书库 | ☐ |
| U9 | 刷新/返回 | 受保护页刷新不闪回登录；后退返回上一页；退出回到登录 | ☐ |
