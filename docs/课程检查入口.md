## 1. 产品范围（一句话）

面向语言学习者的**双语电子书生成系统**：上传单语电子书 → 提取正文与章节 → 逐句/逐段翻译对齐 → 生成原文译文对照的双语电子书（EPUB/PDF 导出），登录后的书籍/任务/下载记录归属到用户，管理员独立入口只读查看。

- **首版（本里程碑）**：TXT 输入、英语→中文、单家真实翻译服务、后台任务与进度、双语预览、EPUB 生成与下载、个人书库、管理员最小只读查看。
- **后续里程碑**：EPUB/PDF 输入、PDF 导出、六语互译、书签/继续阅读、PWA 可安装、完整管理端、OCR 评估等（范围见需求文档 §3.6 与「已确认结论」）。

## 4. 原型如何打开（本地静态查看）

原型为纯静态 HTML/CSS/JS，无构建、无后端依赖，任何静态服务器即可：

```bash
cd ~/projects/bilingual-ebook-generator/prototype/v4
python3 -m http.server 8080 --bind 127.0.0.1
# 浏览器打开 http://127.0.0.1:8080/index.html
```

- 普通用户路径：首页 → 注册/登录（示例账号直登）→ 工作台 → 创建任务 → 任务详情 → 书库 → 阅读器。
- 管理员路径：登录页「独立管理入口」或直接 `admin-login.html` → 概览 → 任务 → 审核。
- 桌面与 390px 窄屏的人工逐页检查步骤见 [浏览器人工验收清单.md](浏览器人工验收清单.md)。

## 6. 遗留问题

1. **浏览器人工验收待完成**：本机自动截图环境受阻（Chrome 无头截图的 localStorage 注入与跳转渲染不稳定），已改为人工逐页验收，桌面 + 390px 检查步骤见《浏览器人工验收清单.md》。
2. **ER 图 SVG 待补**：本机未装 mermaid-cli/mmdc（导出需引入 puppeteer/Chromium），已保留可编辑源 `01-er.mmd`；网页端 mermaid 可直接渲染，离线 SVG 后续用 `npx @mermaid-js/mermaid-cli -i 01-er.mmd -o er.svg` 生成。
3. **上传方案待评审**：`upload_file` 字段与上传接口随 yiban-api 分支评审结果微调。
4. **服务器发布前置条件未满足**：`ebook.dailen.top` 站点目录、HTTPS 与缓存现状未核实；本轮只准备发布物与操作说明，不连接服务器、不覆盖旧站（见《发布说明.md》）。
