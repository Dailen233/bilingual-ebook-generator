## 3. 静态展示版与离线查看

原型为纯静态文件，无构建、无后端。本地/服务器均用任意静态服务器托管：

```bash
# 本地离线查看（任意静态服务器）
cd prototype/v4 && python3 -m http.server 8080 --bind 127.0.0.1
# 浏览器打开 http://127.0.0.1:8080/index.html
```

- **离线方式**：整包下载后本地打开；`.html` 内相对路径引用，`assets/fonts` 与 `icons` 随包携带。
- **Service Worker 缓存边界**：`sw.js` 缓存名 `yiban-v4-shell-v8`（版本内嵌于缓存名）。**发布新版本时需递增 `sw.js` 的缓存名**（v8→v9），避免旧缓存持续命中旧页面；不同版本/应用用不同缓存名保持边界。
- **文档阅读**：Markdown 在 Gitee/GitHub 网页端直接渲染；原始 Markdown 与 `schema.sql`/`01-er.mmd` 以源码链接形式可下载/查看（见 `docs/课程检查入口.md` §2）。

## 4. 部署与回退步骤（进入发布前执行，本轮不执行）

### 4.1 版本目录与配置备份

1. 在服务器上新建**带日期的版本目录**：`/var/www/yiban/versions/20261027/`（或站点约定的版本目录），把本次发布物整体放入，**不直接覆盖旧目录**。
2. 备份当前 Nginx 站点配置与旧站点目录：`cp -a <旧站目录> <旧站目录>.bak-$(date +%F)`、`cp -a <nginx站点conf> <nginx站点conf>.bak`。
3. 记录旧版本目录路径与旧缓存名（`sw.js` 内 `yiban-v4-shell-v*`）。

### 4.2 Nginx 检查

1. `nginx -t` 通过后再 `nginx -s reload`。
2. 核对：站点 `root` 指向**新版本目录**；`index index.html;`；`try_files $uri $uri/ /index.html;`（单页兜底）；静态资源与字体返回正确的 `Content-Type`（`.woff2 → font/woff2`）。
3. 若启用 HTTPS，核对证书路径与 `ssl_certificate`/`ssl_certificate_key` 未指向被覆盖的文件。

### 4.3 上线验证

1. 桌面浏览器走通：首页 → 注册/登录 → 工作台 → 创建任务 → 任务详情 → 书库 → 阅读器。
2. 390px 窄屏（或手机）走通同一路径，核对抽屉菜单、表格与阅读器缩放。
3. 管理员路径：`admin-login.html` → 概览 → 任务 → 审核。
4. 刷新与前进/后退：受保护页刷新不闪回首页；SW 缓存名已递增、无旧页面残留。
5. 校验文件清单 SHA-256 与本地一致。

### 4.4 回退

1. `nginx -t` 通过后，把站点 `root` 切回旧版本目录，`nginx -s reload`。
2. 若旧缓存名仍在 `sw.js` 内，用户端旧缓存自动失效并回退到旧壳；必要时清理用户浏览器缓存。
3. 恢复已备份的 Nginx 配置与旧站点目录。
