How it works

三步，得到你的双语书

主流程尽量压缩为「上传 → 选语言 → 下载」，处理期间可随时离开，回来查看进度与结果。

1

上传一本书

支持 .txt / .epub / .pdf（文本型）。系统提取正文与章节，过滤页眉页脚、目录等噪音。

2

确认语言，开始处理

原文语言默认自动识别，可手动修改；选择目标语言后提交。任务后台处理，展示进度。

3

预览、下载、再找到

对照预览，下载 EPUB / PDF，并在个人书库中随时再次找到与重新下载。

📖

逐段对照

按句子或段落切分对齐，避免整书翻译导致对照混乱。

🌏

六语互译（规划）

中、英、日、韩、法、德为规划目标；实际语言对以所选翻译服务能力核对为准。

⏳

长书可离开

任务后台处理并展示进度；关闭页面后回来仍可查看状态与结果。

📱

移动友好

响应式网页 + 可安装 PWA（后续），手机端可上传、查看、阅读、下载。
