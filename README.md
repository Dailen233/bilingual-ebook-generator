# 译伴 · 双语电子书生成系统

软件工程课程设计项目，面向语言学习者，将单语电子书处理为原文与译文对照的电子书。

当前处于**首个真实可运行里程碑的实现阶段**：需求、设计草案与 v4 交互原型已形成；账号与鉴权已真实实现，整书业务（上传/解析/翻译/任务/EPUB）仍待实现。

更新日期：2026-10-27。

## 首个真实可运行里程碑

以需求文档 §3.5 为开发顺序依据，先打通：

1. 基础注册、登录与服务端属主校验。
2. TXT 输入、英语到中文、接入一家真实翻译服务。
3. 正文提取与对齐、真实后台任务和处理进度、失败单元保留原文。
4. 对照预览、EPUB 生成与下载、个人书库与重新下载。
5. 管理员独立登录、任务及失败元数据只读查看。

EPUB/PDF 输入、PDF 导出、更多语言、完整管理、PWA 与阅读位置等继续按后续里程碑推进。第三方登录作为课堂补充加分项评估排期。完整产品目标与首版范围分别记录。

## 开发与提交

三个实现仓库使用 `master`（稳定）和 `develop`（集成），从 `develop` 创建 `feature/*`、`fix/*` 或 `docs/*` 分支。Gitee 处理 PR，合入后将同一提交同步至 GitHub；稳定批次验收后再从 `develop` 合入 `master`。

本资料仓库目前保留 `main` 及已有历史，文档改动从 `main` 创建 `docs/*` 分支并向 `main` 提 PR。单人开发保留自查、验证与验收记录，关联实际 PingCode 任务。校内 GitLab 按用户安排留到最终提交阶段处理。
